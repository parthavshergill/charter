# The `attention` encoder

A PufferLib encoder for Charter's observation tables (`rl/layout.json`). PufferLib's MinGRU and linear
decoder follow it, unchanged.

For one observation:

1. The one-row tables (`global`, `proposal`) give the context `c`: one linear map and a ReLU, width 32.
2. Each row of the other tables (seats, resources, kinds, tiles, spots, links, laws: 207 rows) is a token:
   a linear map per table and a ReLU, width 32. A row whose `real` column is 0 is padding.
3. Eight heads. Each head asks one question, made from the context (`q = Wq c`). It scores every real
   token, takes a softmax over the real tokens only, and returns the weighted sum of their values. A head
   with no real token returns 0.
4. The heads' answers and `c` go through one linear map to the trainer's hidden size.

No biases: column 0 (`real`) is 1 on every real row, so it acts as one.

26,592 weights at hidden size 128. About 0.27M multiply-adds per observation.

| File | What it is |
|---|---|
| `attention.cu` | The CUDA encoder, with hand-written gradients. `rl/puffer/patches/0003-attention-encoder.patch` hooks it into `src/ocean.cu` |
| `attention_ref.py` | The PyTorch version, the reference |
| `attention_plan.py` | Sizes, where the tables are, and the weights' shapes and order (the checkpoint's order) |
| `attention_np.py` | The NumPy forward `rl/eval` uses, format `puffer-attention` |
| `attention_layout.h` | Generated by `gen_layout.py` from `rl/layout.json` |
| `reference_test.py`, `attention_test.cu` | The reference test, see its docstring |
| `modal_reftest.py` | Runs the reference test on a Modal T4, with real observations |
